# Changelog

## 1.0.0

First public release.

- Menu bar screenshot tool: global shortcut, drag an area, annotate, copy or save.
- Tools: pen, line, arrow, rectangle, text, freehand brush, straight highlighter.
- Five thickness levels (scroll, `[` / `]`, toolbar button).
- Editable marks with undo/redo, last 10 captures, custom capture shortcut.
- Guided Screen Recording setup with self-restart and permission reset.
- Universal binary (Apple Silicon and Intel), macOS 14+.
